## 📖 Overview

The **IoT Heart Monitoring System with AI Dashboard** is an intelligent healthcare monitoring solution that enables real-time heart rate tracking using IoT technology. The system collects sensor data, visualizes it through an interactive dashboard, and provides AI-powered insights to help users monitor their heart health efficiently.

This project demonstrates how **Internet of Things (IoT)**, **Artificial Intelligence**, and **Modern Web Technologies** can work together to build a smart healthcare monitoring platform.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Pratikfating123/IoT-Heart-Monitoring-System-with-AI-Dashboard.git
```

Navigate into the project

```bash
cd IoT-Heart-Monitoring-System-with-AI-Dashboard
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
